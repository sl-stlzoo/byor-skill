Build Your Own Radar

Answer the radar interview on one page

Start with the same software areas and questions as the guided interview. Fill in what you know, skip what doesn’t apply, then give your assistant everything at once.

Strictly client-side. The form reads files and builds exports in your browser. It never uploads answers, calls an AI service, or saves your draft when you leave. Review what you choose to share.

Start With a Spreadsheet, If You Prefer

  1. Download the radar starter CSV. It contains one fictional example and one empty row for each suggested software area.
  2. Keep the headers. Add your tool name and what you know to each applicable area row; leave unused rows empty. Duplicate an area row for more tools. The row marked EXAMPLE is ignored; delete it or change its row_type to BLIP and replace every example value to use it.
  3. Use Adopt, Trial, Assess, Caution for rings and TRUE or FALSE for isNew. Separate multiple evidence or also_in values with semicolons. Use area IDs for domain and also_in, dates in YYYY-MM-DD, and a number from 0 to 1 for radial. Save as UTF-8 CSV.
  4. Import it below to add editable blips, or attach it to a new AI chat with the BYOR interview start prompt.

The starter CSV carries radar blip details, not the organisation-wide context or narrative questions below. For the hosted Thoughtworks radar, choose its four quadrants: Techniques, Platforms, Tools, or Languages & Frameworks. The final Thoughtworks CSV download contains only its five standard fields.

1. Set the Context ↑

Leave unknowns blank. Use roles rather than staff names, and leave out secrets and confidential details. Sections can be reached from these anchors; your draft stays only in this browser tab.

2. Review Your Software Areas ↑

Open the areas you know. Rename an area or add your own. Blank areas stay unanswered; mark an area not applicable if you want to skip it explicitly. Use the live counts to see your progress.

3. Add Individual Blips ↑

Optional for the AI handoff: your assistant can draft blips from your answers above. Extra fields are included in the JSON prompt. For the Thoughtworks CSV download, fill in the five required fields; extra fields stay in the JSON prompt only. Each blip can be edited or removed below.

4. Review & Export ↑

Copy the JSON prompt into a new chat. The CSV contains only blip rows, not your interview notes. Neither action sends anything to an assistant or publishes your radar.
